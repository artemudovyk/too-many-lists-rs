# Too Many Lists in Rust

This is my accompanying repo that I've worked on while going through the [Learn Rust With Entirely Too Many Linked Lists](https://rust-unofficial.github.io/too-many-lists/) book.

Highlights:

- Zero LLM-generated code.
- Almost the entirety of the code after the first module were written in a way to first read about the problem in a book without looking up the solution, then write my own tests, then my approach to the problem, then sync with the book on what I've missed. After that I've usually created an additional test module with the tests from the book separate from my own to finalize the solution.
